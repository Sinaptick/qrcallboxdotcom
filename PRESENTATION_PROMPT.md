**ABOUT QRCALLBOX:**
QRcallbox is a React/Firebase web application that enables customers to scan QR codes in retail stores to instantly request assistance. Staff receive real-time notifications via GroupMe integration, and the system tracks response times with gamification features.

**KEY FEATURES TO HIGHLIGHT:**
1. **QR Code Generation**: Create location-specific QR codes for different store areas
2. **Real-time Notifications**: Instant GroupMe/Workvivo alerts to staff when customers need help
3. **Top Responders Leaderboard**: Live ranking system with 🥇🥈🥉 badges showing fastest/most active associates
4. **Business Hours Analytics**: Response time calculations filtered to 6:00 AM - 10:59 PM
5. **Multi-platform Integration**: GroupMe and Workvivo workplace social platforms
6. **AI-Powered Insights**: Natural language analysis of customer assistance patterns
7. **Heatmap Visualization**: Visual representation of assistance requests by store area
8. **Security Features**: IP blocking, rate limiting, spam protection, admin controls
9. **User Management**: Secure authentication, email verification, admin approval workflow
10. **Support Ticket System**: Integrated customer support with email notifications

**TECHNICAL ARCHITECTURE:**
- Frontend: React 18, Vite, Tailwind CSS
- Backend: Firebase Functions (Node.js), Firestore database
- Authentication: Firebase Auth with email verification
- Hosting: Firebase Hosting with custom domain
- Integrations: GroupMe API, Workvivo API
- Security: Firestore security rules, input sanitization, CORS protection
